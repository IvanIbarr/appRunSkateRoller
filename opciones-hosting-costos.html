RunSkateRoller — Opciones de hosting y costos

Fuente vivo: proyecto con Flutter (iOS, Android y web opcional), API Node/Express y PostgreSQL. Tipo de cambio orientativo: 1 USD ≈ 18 MXN — verificar en el momento del pago.

  • Hosting API + BD igual que antes (Flutter no aumenta ese costo).
  • Flutter Web → flutter build web como estático gratis (Pages / Vercel).
  • Correo: SendGrid sin plan gratuito permanente desde 2025 — presupuestar alternativas (abajo).

1 Qué marca el gasto recurrente

El servidor (API siempre disponible HTTPS), la base Postgres y el volumen real de uso son lo que mueve MXN mensuales. Las cuentas de desarrollador App Store (~99 USD/año Apple) y Google Play son gasto aparte — no sustituyen al hosting backend.

Componente Impacto en costos (Flutter)
Backend Node + PostgreSQL Igual que con cualquier cliente móvil; prioridad número uno en presupuesto.
Flutter Web estático Tiers hobby/gratis habitualmente suficientes al inicio.
Correo transaccional (reset, verify) Variable: entre 0 (Resend capado) y ~20 USD/mes en plan inicial estable.

! Correo desde 2025–2026: costos concretos

Twilio dejó sin plan gratuito permanente a SendGrid — prevalecen pruebas limitadas antes de tener que pagar. Para recuperación de contraseña en producción realista necesitás al menos uno de estos enfoques:

Proveedor / modo Costo típico Notas
Resend · Free 0 USD/mes ~hasta 3 000 correos/mes y habitualmente ~100/día de tope. Buen punto de arranque para beta.
Resend Pro / SendGrid Essentials ~20 USD/mes Orientación típica: paquete del orden ~50 k correos/mes sin el techo diario severo del free. En MXN: ~360–390 (TC).
Amazon SES Por volumen muy bajo Muy barato por mil envíos si dominás infra y reputación SPF/DKIM — más trabajo de integración.
Línea de planificación: Beta con pocas recuperaciones al día suele poder vivir meses en Resend free. Para v1 en comunidad grande o muchos mails el mismo día, reservá en cabeza +360 MXN/mes (~20 USD) cuando el tier gratuito ya no aplique — es el mismo orden de magnitud que Resend Pro o SendGrid pagado inicial.

Recomendación resumida por fases

Fase 1 Máximo free tiers con Postgres real para no engañarte con mock permanente · seguí el reporte ejecutivo para matriz de pruebas; presupuesto caja típico ≤120 MXN/mes hasta validar comunidad cerrada.
Fase 2 En cuanto haya instalaciones “de verdad” y calendario compartido, saltá a Render API+Postgres (~300–340 MXN/mes); dominio sí o sí para confianza.
Fase 2+ Si los envíos rompen el cupo gratuito (~100 mails/día) o necesitás plan estable día 1, sumá desde el modelo B′ (~630–690 MXN/mes; ~7,9k–8,3k/año).
Fase 3 Escala sólo componentes que midas (DB, RAM, Mapbox, almacén); la banda anual va aproximadamente de 5,4 k a 13 k+ MXN según uso.

6 Recomendación técnica resumida

  1. Web: desplegar build/web en Pages o Vercel — costo marginal.
  2. Prioridad estable: API + Postgres con plan que no duerma en horario punta de tus rodadas (p. ej. Render o Railway con alertas de gasto).
  3. Correo: empezá con Resend capado; ante v1 pública o picos (>100 mails/día) migrá mentalmente el presupuesto a B′ (~630–690 MXN/mes combinado con Render según ejemplo).
  4. Fases beta → público: igual lógica del documento fuente Markdown: no prometer SLA de tienda gratis sin monitoreo.
